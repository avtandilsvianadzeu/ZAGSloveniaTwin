Data API

All atlas data can be read by address, with no key and no sign in. Use it in QGIS, Python, Excel or your own viewer. It is read only and it is rebuilt from the atlas files each time the data changes.

Fields of an object record

  
FieldMeaning

    
id, name, name_sl, type, placeIdentity of the object

    
latitude, longitude, position_basis, position_exactStored point in WGS 84 and how it was placed

    
zag_work_from, zag_work_to, zag_roleDocumented ZAG involvement

    
specificationsEach value with label, unit, source link and, where held, the quoted sentence it was read from

    
source_differencesCases where sources give different values. None is chosen

    
open_questionWhat is not yet verified

    
geometryPoint, drawn alignment if any, official building outline and height if any

    
model_basisPublished dimensions a rebuilt model uses, with its drawing choices

    
rebuild_statusWhether a true model can be built from published data and what is missing

  

  
Each source keeps its own licence. The atlas holds no sensor readings, so nothing in the API is measured live.
